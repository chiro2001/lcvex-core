## 1. 完成内容

### rtl/lcvex_l1_d（D-L1 数据缓存）

- 直接映射，64 B line / 64 组 = 4 KiB，物理地址 tag/index/offset，
  单阻塞 miss。
- 完全复用 M1-B 的 `mem_req/mem_rsp` valid/ready 协议：上游接
  core.dmem，下游接仲裁端口 1，不改核心。
- 读命中 1 拍返回；读未命中 8 次 8B 下游读填整行后返回。
- 写通：下游写完成后才响应上游；行命中同步更新
  （write-allocate-on-hit），未命中不分配（no-write-allocate）。
- 下游 fault 原样上抛（核心转 DABT）；未完成填行作废；
  写 fault 时行数据与内存不一致，作废该行。

### 验证

- `tb/sv/lcvex_l1_d_tb.sv`（`make sim-sv-l1d`）：写通/读命中/读 miss
  填行/写命中行更新/冲突替换（同组异 tag）/越界 fault 全部通过。
- SoC `D_L1_ENABLE=1` + `make lockstep-build-l1d`：p4c 7 组、p5a 3 组、
  hardening 9 组、q6、P2 lockstep 36 条全部与 QEMU 锁步一致（含断言）。

### 过程中修复

- TB do_req 撤销 valid 与 L1 采样竞争：ready 后多等一拍再撤销。
- L1 refill 地址位宽（`{16'd0,...}` 造成 80 位截断）与写 fault 行一致性。

## 2. M2 剩余（下一步）

按 PROJECT_STATUS M2 顺序：

1. `lcvex_l1_i`：I-L1 只读缓存（结构与 D-L1 对称，无写通路径）。
2. 统一 L2：32 KiB、2-way、64 B line（先正确性与替换可验证性）。
3. ISB（冲刷并重取）、DMB/DSB（等待相关未完成访问）——不能当 NOP。
4. DC/IC/TLBI 最小明确子集；MAIR Device/不可缓存旁路。
5. 系统回归：hit/miss/refill/evict、冲突替换、脏/写穿副作用、I/D 失效、
   Device bypass、TLB hit/miss/fault、可注入下级延迟。

Gate D 退出条件满足前，P5b 不宣称完成；R1 遗留（TLBI 一致性、
ESR/FAR 完整 syndrome、块描述符）在 Linux 阶段前关闭。
