## 独立外部审计摘要（原 PE-EXT）

1. 核心为单发射、顺序、顺序提交；单在途取指、单响应槽、分支 ID 解析后冲刷、访存单 outstanding，造成前端和访存等待被串行化。
2. P-line 默认关闭 I-L1/D-L1/L2，14 项快照只是无缓存整程序 cycle 代理。
3. 缓存/I/D/L2 多为单阻塞、8×8B beat refill/writeback，没有 MSHR、写缓冲、critical-word-first、hit-under-miss。
4. 共享 L2 cluster 只有目录元数据，没有共享数据阵列；全局单事务、probe 串行。
5. M1-B、AXI master、Avalon 后端均为单 outstanding；异步 FIFO 只是 CDC，不提供事务并行。
6. 外部建议：P0 测量矩阵；P0 取指 FIFO/early restart；P1 受限 MSHR/store buffer；P1 共享 L2 数据阵列/probe 并行；P1 总线 line burst/多 ID；P2 深流水和 2-wide。

## PE-A 与 PE-EXT 综合结论

- **强共识**：先做测量；再取指前端；再做受限访存并行；再做多核/总线；深流水和 2-wide 后置。
- **主要差异取舍**：PE-EXT 将分支预测拆为 F1 取指 FIFO/early restart（P0）与 F2 BTB/RAS（P1），PE-A 将两者合并为 P0；最终采纳拆分，降低预测误路径风险。
- **Top 3 最终建议**：
  1. F0 性能计数与缓存配置矩阵（P0）
  2. F1 取指 FIFO/早取/critical-word-first（P0）
  3. F3 受限 outstanding/MSHR/store buffer（P1）
- **最终路线图优先级**：F0/F1/F6 为 P0/P0-P1；F2/F3/F4/F5 为 P1；F7 为 P1/P2；F8/F9/F10 为 P2。
