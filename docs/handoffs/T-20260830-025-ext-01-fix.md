`scripts/check_task_timestamps.py` 已实现：

- `EVENT_KEYS` 与 `LEDGER_KEYS` 分离，`*_at` 默认按事件处理；
- 事件时间不得晚于 now（涵盖 `review <= now`）；
- 事件时间不得晚于承载 Git 提交（`git blame`）；
- `integrator_review.received_at >= dispatch.sent_at`、
  `merged_at >= dispatch.sent_at`、
  `runs[*].started_at >= dispatch.sent_at`、
  `started_at <= finished_at`；
- 顶层报告链 `sent_at <= received_at <= reported_at`。

  当前事件时间再次检查。
