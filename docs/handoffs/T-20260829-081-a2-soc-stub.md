## 结论

- **真实顶层可通过 Verilator elaboration。** 新建
  `fpga/opensynth/rtl/lcvex_catapult_soc_tieoff.sv` 包住
  `rtl/lcvex_catapult_soc_top.sv`，只保留 `clk`/`rst_n` 作为外部输入；
  EMIF/calibration、Avalon、JTAG-UART、EPCQ/SFL、BRAM 程序/调试、
  checkpoint 等外部边界全部 tie-off。Verilator lint 完成 elaboration，
  以 `-Wno-fatal` 退出 0；原有 `UNSIGNED`/`MULTIDRIVEN` warning 作为已知项保留，
  未改 RTL。
- **Yosys generic synth 在本任务只对普通 Verilog 边界 stub 通过。**
  `fpga/opensynth/rtl/lcvex_catapult_soc_stub_top.v` 镜像真实 SoC 顶层端口
  （109 ports / 2627 port bits），所有输出 inactive 常量。Yosys `synth -lut 4`
  两次均 exit 0、`num_cells=0`、netlist SHA256 一致。
- **ECP5/nextpnr 不会伪造 Fmax。** `nextpnr-ecp5` 可用，但边界 stub 的
  2627 port bits 远超 ECP5 LFE5U-85F 的 365 个 I/O cell，pack 阶段无法放置全部
  `TRELLIS_IO`。因此 A2 的 ECP5 结果记为 **N/A**，不是 A10，也不是 Fmax。
- **真实 SoC 未直接给 Yosys**：A0 已确认 Yosys 不能解析当前 RTL 的
  package/import、unpacked-array 端口等；A2 未为迁就工具修改任何 RTL。
