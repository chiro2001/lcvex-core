| `sys_clk_50` removal -5.480 / EMIF IP→CPU hold 红 | EMIF 校准/复位状态和 adapter 中未同步的 `cal_fail` 使用进入 CPU 域寄存器 | 增加 calibration-gate 首级同步 false path；增加 EMIF IP → CPU 域 SoC/adapter 寄存器的异步控制 false path；同时记录 raw `cal_fail` 仍需 RTL 同步，不能由约束替代 |
