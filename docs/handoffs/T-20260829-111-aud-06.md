## Canonical 定义

- 文件范围：`qemu/patches/*.patch`（12 个，匹配 `^[0-9]{4}-.*\.patch$`）。
- 排序：按文件名固定字节序（`LC_ALL=C`，脚本按 `name.encode()` 排序）。
- 文件边界：不插入文件名、分隔符、NUL 或空行。
- 内容边界：每个 patch 的仓库工作区原始字节，含自身已有结尾换行。
- 组合：对排序后的原始字节流直接串接后计算 SHA256。

等价 shell 命令：

```sh
LC_ALL=C find qemu/patches -maxdepth 1 -type f -name '*.patch' -print0 \
  | sort -z | xargs -0 cat | sha256sum
```
