## 1. 两类时间字段定义

| 类别 | 含义 | 字段示例 |
| --- | --- | --- |
| 事件发生时间 | 流程中真实发生的事件时点：派发、接收、报告、运行、评审、合并 | `dispatch.sent_at`、`sent_at`、`received_at`、`reported_at`、`run_at`、`runs[*].started_at/finished_at/ended_at`、`integrator_review.received_at`、`merged_at`、`event_at` |
| 台账回填时间 | 记录被创建/写入/更新到台账的时点，不用于耗时计算 | `created_at`、`updated_at`、`recorded_at`、`archived_at`、`documents_written_at` |

强制规则（已写入 `docs/audit/01-governance.md` 和 `docs/MULTI_AGENT_WORKFLOW.md`）：

- 事件时间不得晚于当前时间，也不得晚于承载该字段的 Git 提交时间。
- `review >= dispatch`、`run >= dispatch`、`sent <= received <= reported`、
  `started <= finished`、`created <= updated`。
- 新记录提交前运行 `python3 scripts/check_task_timestamps.py --scope live --exit-code`。
- 历史不一致用 correction record 保留旧值；不改写已冻结 handoff/evidence。
