# T-20260826-010：ADC/SBC carry 宽度 lint 修复

`rtl/lcvex_alu.sv` 中 ADC/SBC 的 32 位和 64 位 carry 临时量原声明为
34/66 位，实际表达式只产生 33/65 位，Verilator `-Wall` 将未使用最高位
报告为 fatal。已将声明改为 `[32:0]` 和 `[64:0]`，未改变已有取位、结果或
标志逻辑。

验证：`make compile` 在 conda:lcvex / Verilator 5.050 下通过。完整 Gate D
及 LSE 回归交给新的 candidate SHA 复跑；本修复不关闭警告/断言。
