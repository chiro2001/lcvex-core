## 交付内容

新增 `baremetal/perf/` 下四个可复现的混合 kernel 功能 sanity workload：

| 文件 | 入口 | 固定规模/迭代 | 校验方式 |
| --- | --- | ---: | --- |
| `t_kernel_crc.c` | `int run_test_crc(void)` | 256 B 数据、4 次迭代 | CRC32 查表 vs 逐位一致；已知 `"123456789"` 向量 |
| `t_kernel_matmul.c` | `int run_test_matmul(void)` | N=16、2 次矩阵乘 | 对 16x16 整数矩阵乘与闭式参考逐项比较 |
| `t_kernel_sort.c` | `int run_test_sort(void)` | 64 元素、4 次插入排序 | 逆序输入排序后必须得到 0..63 |
| `t_kernel_hash.c` | `int run_test_hash(void)` | 256 B 数据、4 次 FNV-1a | 多轮 FNV-1a 摘要与标准 `"123456789"` 向量 |

每个文件自包含，未依赖尚未合入的 `perf_common.h`；只做功能 sanity，返回 0 表示通过，
不声明任何性能指标。为兼容 P-INFRA 提出的 `PERF_ONLY`/`run_perf_*` 构建路径，每个文件
额外提供 `run_perf_<name>()` 薄别名并转调对应的 `run_test_<name>()`。未修改
`scripts/`、`Makefile`、`baremetal/microbench_main.c`，未引入 SVE，未运行
Verilator/Quartus。

## 本地验证

交叉编译（与 `scripts/build-microbench.sh` 相同的 freestanding/general-regs-only 风格）：

```sh
for f in baremetal/perf/t_kernel_crc.c baremetal/perf/t_kernel_matmul.c \
         baremetal/perf/t_kernel_sort.c baremetal/perf/t_kernel_hash.c; do
  aarch64-linux-gnu-gcc -O2 -ffreestanding -nostdlib -nostartfiles \
    -mabi=lp64 -mgeneral-regs-only -Wall -Wextra -c "$f" -o /tmp/$(basename "${f%.c}").o
done
```

结果：四个文件均编译通过，无警告。

主机侧功能 sanity（临时 driver，仅验证算法与常量）：

```sh
gcc -O2 -Wall -Wextra -o /tmp/perf_driver /tmp/perf_driver.c \
  baremetal/perf/t_kernel_crc.c baremetal/perf/t_kernel_matmul.c \
  baremetal/perf/t_kernel_sort.c baremetal/perf/t_kernel_hash.c
/tmp/perf_driver
```

结果：`crc=0 matmul=0 sort=0 hash=0`，退出码 0。
