## 结论

1. **行为级 `logic [7:0] mem[0:DEPTH_BYTES-1]` 是 Quartus 21.4 综合的主要深渊**：
   - 仅 16KB 的 `lcvex_bram_boot` standalone synthesis 在 10 分钟窗口内未完成；
   - `(* ramstyle = "M20K" *)` 和 baseline 行为级版本都不能在 10 分钟内完成；
   - 说明单纯加 `ramstyle` 属性不能解决该行为级数组在 Quartus 中的展开/推断问题。
2. **显式 `altera_syncram`（M20K, BIDIR_DUAL_PORT）包装彻底解决**：
   - standalone 容量矩阵全部快速通过（3–4s，峰值 PM 0.46–0.66GB）；
   - Quartus 明确报告 `M20K block / True Dual Port`，0 MLAB bits；
   - 1MiB 也用 512 个 RAM 段，655MB 峰值 VM。
3. **SoC-only 顶层复测**：把 `lcvex_bram_boot` 换成 `lcvex_bram_boot_altsyncram` shim 后，沿用 F3/F4 的 core/coh/AXI black-box stub 工程：
   - **8 秒通过**，0 errors，峰值 PM 0.63GB / 峰值 VM 0.75GB；
   - 对比 F3/F4 行为级 BRAM 版本：约 85 秒到达 31.3GB 被 30GB 保护线中止。
   - 因此 31.3GB 不是 SoC top glue 展开，而主要是行为级 BRAM 数组的 Quartus elaboration/synthesis。
4. **D（L1D/L2 ramstyle）**：
   - L1D `data[0:SETS-1][0:LINE_BYTES-1]` 加 `(* ramstyle = "M20K" *)` 后 standalone 通过（4m36s、峰值 PM 3.9GB），但报告中 **Block Memory Bits=0，data 仍被综合为 LEs**；属性被记录但 Quartus 未形成 M20K。
   - L2 结果见下（同 `ramstyle` 实验，实际也是 0 block bits）。

## D：L1D/L2 数据阵列 `ramstyle=M20K`

### L1D（`lcvex_l1_d_wb`，SETS=64, LINE_BYTES=64）
- 结果：PASS，0 errors，8 warnings；
- 墙钟 4m36s，峰值 PM 3,930 MB，峰值 VM 3,639 MB；
- Logic cells 182,885（与历史 T-008 baseline 182,885 一致）；
- **Block Memory Bits = 0**；报告中的 `RAMSTYLE_ATTRIBUTE=M20K` 只表明属性被记录，实际 data 阵列没有形成 M20K，仍是大规模 LUT/寄存器实现。
- 结论：**仅给 L1D 数据阵列加 ramstyle 不能获得 M20K**。

### L2（`lcvex_l2_wb`，SETS=64, WAYS=1, LINE_BYTES=64）
- 结果：PASS，0 errors，87 warnings；
- 墙钟 5m15s，峰值 PM 4,364 MB，峰值 VM 4,572 MB；
- Logic cells 179,258（与历史 T-008 reduced baseline 179,258 一致）；
- **Block Memory Bits = 0**；`RAMSTYLE_ATTRIBUTE=M20K` 同样只记录属性，未形成 M20K。
- 结论：**cache 数据阵列的 ramstyle 属性不足以实现 M20K 映射**。

## 建议

1. **主 RTL 优先采用显式 `altera_syncram`/`altsyncram` 包装替换 `lcvex_bram_boot` 行为级数组**。这是本次唯一能同时通过 standalone 和 SoC-only black-box 顶层并维持 M20K 映射的方案。
2. 若担心未对齐访问，wrapper 需要补字节 lane 旋转/交叉逻辑；或者使用完整字节 lane 版本（会增大 RAM/逻辑，但可保持严格等价）。
3. 对 L1D/L2 数据阵列，不要把 `ramstyle` 当作已解决问题；数据访问模式不能自动映射到 M20K（L1D 实测 Block Memory Bits=0）。后续应为 cache 数据阵列引入显式 RAM wrapper 或多周期字节 lane 抽象。
4. 在纳入主 RTL 前应补 Verilator 功能验证（读写/未对齐/dbg/prog 语义）和 Quartus fit/STA 验证。
