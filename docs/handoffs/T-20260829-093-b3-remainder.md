## 审计结论

在 V82-BASE + V82-SELECTED-EXT 已批准范围内审计当前 `feature/p7-final`：

- DMB/DSB/ISB/SB：编码与 EL0/EL1 权限已符合 QEMU a64.decode；
  SB 仅接受 CRm=0，DSB/DMB 接受任意 domain/types。
- TLBI/DC/IC/AT：已有 EL1 基线、EL0 DC ZVA/DZE、EL0 cache UCI 门控；
  DC CVADP、TLBI OS/RV/range、EL2/EL3 属于 POST-V82-DEFERRED，未实现。
- LSE 单寄存器原子、CAS、LDXR/STXR、LSE128 选定子集：均在 decoder 中识别，
  本次补充解码矩阵证明 B/H/W/X、acquire/release、ST* 别名等路径可用。
- 发现一个可低成本补上的系统寄存器缺口：`OSLSR_EL1` 未实现。
  QEMU 11.1.0 将其定义为 `PL1_R`、reset 10；原 RTL 将 `S2_0_C1_C1_4`
  判为未知 SYS 而 UDEF。

## 本切片改动

1. 增加 `OSLSR_EL1`（S2_0_C1_C1_4）：
   - `rtl/lcvex_pkg.sv`：新增 `SREG_OSLSR_EL1`。
   - `rtl/lcvex_decode.sv`：解码 tuple，MRS 返回 QEMU 复位值 10；
     MSR 拒绝为 UDEF（read-only）。
2. 扩展 `tb/sv/lcvex_b3_sysreg_access_tb.sv`：
   - MRS OSLSR_EL1 == 10；
   - MSR OSLSR_EL1 == UDEF。
3. 新增 `tb/sv/lcvex_b3_atomic_barrier_tb.sv`：
   - LSE LDADD/STADD/SWP/CAS 全尺寸、acquire/release 组合；
   - LDXR/LDAXR、STXR/STLXR；
   - EL0 DMB/DSB/ISB/SB 权限；
   - 保留 LSE op 负测 UDEF。

未新增 CONTEXTIDR_EL1 等带状态寄存器，避免在 DUT shared core 中扩大写集；
本次修改不触碰 `rtl/lcvex_core.sv`、`rtl/lcvex_mem.sv`、L2 目录协议、
QEMU fork、checkpoint 协议。
