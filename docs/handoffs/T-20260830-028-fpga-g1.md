# T-20260830-028 FPGA-G1：全 stub SoC 顶层外壳（superseded by G2）

- 状态：done/superseded
- 原因：G1 实验在运行期间被用户暂停以避免与 FPGA-G2 并发 Quartus。
- 结论：FPGA-G2（T-20260830-029）已经用更直接的实验回答了 G1 的核心问题：
  - F3/F4 SoC-only 31.3GB 的根因是行为级 BRAM byte-address 数组，不是 SoC top glue/端口展开；
  - 将 BRAM 替换为显式 `altera_syncram` 后，同一套 core/coh/AXI stub 的 SoC-only 顶层 **8s / 0.63GB** 通过；
  - 因此不再需要单独运行全 stub 顶层实验来证明“顶层端口不是主因”。
- 下一步：按 G2 结论优先将主 RTL BRAM 改为显式 RAM wrapper；G3 继续处理 A10 debug fabric / 原工程路径副本。
