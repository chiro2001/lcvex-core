# LCVEX 交接文档 036：PL011 UART（P6 平台第一外设）

日期：2026-08-24（Asia/Shanghai）
前置：handoff 035（RTL 内存模型 128 MiB）。

## 1. 方法：QEMU 探针实证 + RTL 语义复刻

QEMU 11.1.0 的 virt PL011（0x09000000..0x09001000）语义用
`qemu_probe.py` 逐寄存器取证：

- 复位：`FR=0x90`（TXFE|RXFE）、`CR=0x300`（TXE|RXE）、`IFLS=0x12`，
  其余 0；`TXFF` 在 QEMU 中从不置位（TXFE 恒 1）；
- 写 `UARTDR`：`int_level |= INT_TX(0x20)`（读 `RIS=0x20`），FR 不变；
- `CR.LBE`（bit7）时写 UARTDR 回环进 RX FIFO（深度 `FEN ? 16 : 1`）；
  深度 1 时 1 字节即满（FR=0xC0），读 `DR` 弹出，**空读返回残留字节**
  （`read_pos` 按 `(pos+1) & (depth-1)` 回绕）；
- 字节读返回完整寄存器值到低字节（无 lane 位移）；8B 读 = 两个相邻字
  （`{word+1, word}`）；寄存器按 `addr[11:2]` 字解码；
- ID 寄存器（0xFE0..0xFFC）：0x11/0x10/0x14/0x00/0x0D/0xF0/0x05/0xB1。

探针教训：a64.py 的 `ldr/str` imm12 按 8 字节、`ldrw/strw` 按 4 字节、
`ldrh/strh` 按 2 字节缩放，传字节偏移会读到未映射地址（返回 0）。

## 2. 实现

- **`rtl/lcvex_pl011.sv`**：PL011 模型（UARTDR/RSR/FR/ILPR/IBRD/FBRD/
  LCR_H/CR/IFLS/IMSC/RIS/MIS/ICR/DMACR + ID），TX 脉冲输出（观测用）；
  8B 访问拆低/高字（QEMU max_access_size=4 语义）；
- **`rtl/lcvex_mem_router.sv`**：RAM/MMIO 地址路由，组合转发（零额外
  延迟），仅锁存目标选择路由响应；均不命中回 fault；
- **MMU**：PA 落 RAM 或 MMIO 窗口合法（不 fault）；MMIO 强制
  `cacheable=0`（TLB 命中/填充一致）；
- **decode/core**：MMU 关闭时 MMIO 窗口访存放行（不 DABT），且
  `mem_cacheable=0`（bypass=1）→ L1D/L2 直通不分配；
- **soc_tb**：延迟注入器后接 router → {mem_ram, pl011}；UART TX 信号
  提升为顶层输出。

## 5. 已知限制与下一步

- 字节/半字/非对齐 MMIO 访问的 lane 语义按探针实现（读返回完整寄存器
  值到低字节）；Linux 只用对齐 32 位访问，超出范围的行为未承诺；
- QEMU `pl011_read_rxdata` 空读返回残留字节属 QEMU 自身语义，已复刻；
- **P6 剩余**：Generic Timer（CNTFRQ/CNTPCT 已就绪）→ GICv2 → Device
  Tree → PSCI → Linux early boot（Gate E）。
