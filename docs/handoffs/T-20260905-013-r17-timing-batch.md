## 结论

R17 将普通 FP round-pack 拆为 pp_pre → pack_pre → pack_mid，删除 TX_DONE
response-ready 对 accumulator 的死 payload 清零，并修复 EX/MEM 接收、FP response
与 data-MMU/atomic overlap。验证中发现并修复了历史 hard_neon_fetch_fault
的假绿：镜像现在显式启用 FPEN、把 Q-store 页设为 EL1-RW，并用独立
semantic guard 证明页末 STR Q 的两条 8-byte store 与随后 EC=0x21 IABT。

完整联合 L0-L2 已在精确 738cc142 上重启并通过；P7-2 Q-store 第二半 fault
BFM 在登记断言处按预期失败。详细命令、日志 SHA、工具和 coordinator hash 见
evidence。
