## 结论

实现提交 `ffe61e36a9df7dbc7a8197459a34e65d15302ba7` 只修改登记的 RTL 路由区和独立
SystemVerilog TB。非 half `IT_ARITH` 现在以闭合 `unique case (ap_pre.op)` 穷举三类
路径：

| 捕获操作 | 下一状态 | 既有专用路径 |
| --- | --- | --- |
| `FP_OP_ADD`、`FP_OP_SUB` | `IT_ALIGN` | `binary_align_parts(ap_pre)` |
| `FP_OP_MUL`、`FP_OP_FMADD`、`FP_OP_FMSUB`、`FP_OP_FNMADD`、`FP_OP_FNMSUB` | `IT_MUL` | `mul_product_pre(ap_pre)` |
| `FP_OP_SCVTF`、`FP_OP_UCVTF` | `IT_PREP` | `int_to_fp_pre(...)` |

`default` 仅将 `pp_pre` 清零并进入原有 `IT_PREP` 边界，不调用宽的
`binary_pre_parts(ap_pre.op, ...)`。在当前非法操作完成路径中，随后回到 `IT_IDLE` 并
暴露确定性零 result/flags；支持操作的状态、延迟和 round/pack 均未改变。

## TB 覆盖

新增 `tb/sv/lcvex_fp_scalar_r20_route_tb.sv` 是独立 `FP_ITER=1` scalar probe：

- 对上述九个非 half 操作逐一检查 `ap_pre.op` 捕获、目标状态和 raw bits/flags，最后
  检查九项 route bitmap 全覆盖；
- 检查 half ADD 的 `ap_pre_lo/hi -> IT_ALIGN` 双 lane 和 half FMA 的 `IT_MUL` 路径，
  证明非 half case 没有吞掉原 half route；
- 在 `IT_ARITH` 暂停时改变 live operands，确认状态和捕获 payload 保持；覆盖 kill、
  reset、valid-drop 后的清理/reissue；
- 通过层次化 force 将不可达捕获 op 设为 `FP_OP_NONE`，检查 default 的 `IT_PREP`/零
  payload 及后续确定性零完成。该 force 是测试专用，因此 Verilator lint 会给出预期的
  `MULTIDRIVEN` 警告；没有关闭断言或修改参考值。

RTL 中新增的四条局部 route next-state assertion 位于 `ifndef SYNTHESIS` 下，分别约束
ADD/SUB→`IT_ALIGN`、MUL/FMA→`IT_MUL`、SCVTF/UCVTF→`IT_PREP` 和非法 default→
`IT_PREP`/zero；pause/kill/valid-drop 周期显式排除，避免改变状态控制语义。

- 写集严格限于 `rtl/lcvex_fp_scalar.sv` 的 `g_iter.IT_ARITH` 非 half route 和独立 TB；
  没有修改 `iter_state_t`、`IT_PACK`/`round_pack_p2`/slot output、half route、公共接口、
  latency 表、共享测试入口、QEMU、QSF 或 SDC。

  256-bit 对齐、乘法或 generic binary helper 被综合进该不可达分支。
- route assertion 受 `SYNTHESIS` guard 保护，避免验证逻辑影响 physical timing；集成构建
  仍应保留 `--assert` 运行新 TB 与既有断言。
