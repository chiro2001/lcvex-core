## 实现摘要

pre-fix 在 FIFO 填充后的 WB-empty 窗口稳定复现：ready 拉低后
`fetch_fifo_pop=0`、`stall_if=0`，而 IFID 在下一拍从 valid 清为 bubble。修复只从
FIFO-on `fetch_fifo_pop` 移除 `commit_ready`；WB 已有条目时仍由 `stall_wb` 禁止
pop，WB 为空时允许 FIFO/IFID 正常推进。对应 FIFO SVA 从“ready 低必不 pop”收紧为
“WB valid 且 ready 低必不 pop”，并新增 IFID 不丢泡性质。

T-046 的 `memwb_committed_r`/`dmem_pending` 修复、流水 token/SVA、公共 commit
packet/memory ABI、FIFO-off legacy 语义均保留。新增 `hard_fetch_ready_hold` 镜像含
magic store，纳入 `run_f1a.sh` 的 base/cache/delay2 矩阵。
