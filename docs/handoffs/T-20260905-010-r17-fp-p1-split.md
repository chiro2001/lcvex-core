## 结论

本 lane 针对 T-008 retry3 `sys_clk_50` setup top-50 中的
`fp_exec.scalar_unit.g_iter.pp_pre -> fp_exec.scalar_unit.g_iter.pack_mid`
组合锥：26/50 条路径、65 logic levels、slack `−4.797..−4.683 ns`。
最差实路径是 `pp_pre_lo.sig[251] -> pack_mid_lo.mant[97]`，data delay
`24.996 ns`。

实现把普通 `pp_pre` round-pack p1 拆成一个新的真实寄存器边界；随后以独立修复
commit 恢复 `round_pack_h` 的局部 `integer emax` 声明，消除本 lane 引入的
隐式标识符风险：

1. `IT_PREP` 调用 `round_pack_pre`，完成 leading-one scan、normal/tiny
   指数分类和特殊值元数据捕获，写入 `pack_pre*`。
2. 新增 `IT_PACK_PRE`，调用 `round_pack_p1`，只从已注册的 leading-one
   metadata 构造归一化 mantissa、guard/sticky/discarded，写入 `pack_mid*`。
3. 既有 `IT_PACK` 调用 `round_pack_p2`，完成 increment、overflow、subnormal、
   FZ/AHP、最终 pack，并产生唯一的 `iter_done/result`。

迭代 DIV/SQRT 仍由 `IT_FIN` 调用独立命名的 `round_pack_iter_p1`，直接进入既有
`IT_PACK`；没有增加 iterative latency。没有新增组合 bypass，没有修改公共接口、
core、NEON、package、QEMU、QSF 或 SDC。

## 状态、reset、kill、valid 与 pause

- 新增 `fp_round_pre_t pack_pre/pack_pre_lo/pack_pre_hi`，它们是非架构流水
  payload；reset 和 `iter_kill` 将其及 `pack_mid*` 全部清零，并把
  `it_state_r` 置为 `IT_IDLE`。
- `IT_PREP` 遇 `valid=0` 回 `IT_IDLE` 并清理两级 round-pack payload；
  `IT_PACK_PRE` 遇 `valid=0` 同样回 `IT_IDLE`、清理 `pack_pre*`/`pack_mid*`，
  不产生 `iter_done`；`IT_PACK` 的 valid-drop 语义保持不变。
- `iter_pause` 保持状态和 payload；暂停期间 `IT_PACK_PRE` 不推进、最终
  `IT_PACK` 不产生 `iter_done`，解除后继续使用已锁存 payload，不重读 live operands。
- 特殊值、zero sign、NaN/DN、FZ/FZ16、AHP、四种 RMode、input FPSR flags、
  FCVT 单 lane、packed-half 双 lane 和 NEON slot 顺序沿用原 helper 语义。
  架构 V/GPR/NZCV/FPSR 仍只经既有 slot/response/commit 路径更新。

## Latency 影响

每个走普通 `pp_pre -> round_pack` 的 scalar slot 增加 1 周期；NEON 按 slot
累加。相对当前 Round16/T-008 基线的预期表如下：

| 路径 | 变更前 | 变更后 |
| --- | ---: | ---: |
| scalar FADD/FSUB S/D/H | 8 | 9 |
| scalar FMUL/FMA 四族 | 7 | 8 |
| scalar SCVTF/UCVTF | 6 | 7 |
| scalar FCVT（含 H source 单 lane） | 5 | 6 |
| NEON FADD/FSUB.2S | 15 | 17 |
| NEON FADD/FSUB.4S | 29 | 33 |
| NEON FMUL/FMA.2S | 13 | 15 |
| NEON SCVTF/UCVTF.2S | 11 | 13 |
| CMP、FMIN/FMAX、FRINT、FCVTZS/FCVTZU | 不变 | 不变 |
| FDIV/FSQRT 及 NEON iterative FSQRT | 不变 | 不变 |
| FMOV | 不变的组合 passthrough | 不变 |

暂停周期不计入 nominal latency；它们只在状态机保持期间额外累加。

## 定向测试变更

`tb/sv/lcvex_fp_exec_tb.sv` 增加/更新了直接 `FP_ITER` 检查：

- IT_PREP、IT_PACK_PRE、IT_PACK 三个状态的 valid-drop 后 reissue；
- IT_PREP、IT_PACK_PRE、IT_PACK 三个状态的 kill 后 reissue；
- IT_PREP、IT_PACK_PRE、IT_PACK 三个状态的 reset 后 reissue；
- 新 IT_PACK_PRE 的 pause/hold：改变 live operands 后仍返回原输入的 raw result 和
  IXC flags，并只产生一个 done pulse；
- 普通 scalar/NEON round-pack latency 断言按每 slot +1 更新；DIV/SQRT latency
  断言保持原值。
