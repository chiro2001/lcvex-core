## 实现结论

限定写集可以闭合，无需修改公共端口、core/wrapper、QEMU、QSF/SDC、
`round_pack_scan` 或 T-029 的 `IT_ARITH/ap_pre/pp_pre` 路由。

- `iter_state_t` 新增私有 `IT_PACK_RESULT=4'd13`。
- 新增 `pack_result_r/pack_result_lo/pack_result_hi`（`fp_calc_t`）、
  `pack_result_half_r` 和 `pack_result_valid_r` 私有寄存器。
- `IT_PACK` 对 ordinary `pack_mid*` 或 iterative `it_fin_mid*` 只执行一次
  `round_pack_p2` 并写入上述寄存器，随后进入 `IT_PACK_RESULT`；输出组合逻辑不再
  调用 `round_pack_p2`，因此 `pack_mid -> slot_result_r` 不再同周期穿越完整
  round/output mux。
- `IT_PACK_RESULT` 是唯一 result/flags/done 窗口。普通与 DIV/SQRT 共用同一边界；
  H 双 lane 结果和 flags 在该边界合并，FCVT 的 H source 仍保持单 lane。
- `iter_pause` 保持 `IT_PACK_RESULT` 与已寄存 payload，result/flags 保持稳定且
  `iter_done=0`；解除暂停后只产生一个 done 窗口。
- reset、`iter_kill`、`IT_PACK`/`IT_PACK_RESULT` 的 valid drop 清除/丢弃最终
  payload；最终窗口的 valid drop 即使与 pause 同时发生也会取消结果。valid 在
  结果窗口前撤销不会提交 stale result；done 在下一采样边沿回到 `IT_IDLE` 后不重复。

该寄存器组是非架构状态；V/GPR/NZCV/FPSR 仍只经既有 slot/response/commit 路径
更新。结果寄存器 reset 值为全零，读写权限为模块内部时序逻辑，提交时机为
`IT_PACK` 边沿写入、下一 `IT_PACK_RESULT` 窗口由上游 slot capture 采样。

## Latency delta

唯一变化是每个经过最终 round-pack 的 shared scalar slot 增加恰好 1 个周期：
`IT_PACK` 的 p2 计算周期不再同时作为输出周期，新增一拍 `IT_PACK_RESULT`。
暂停周期不计入 nominal latency。DIV/SQRT 的 divider/sqrt 迭代次数和前级状态不变，
但其最终 result/flags 同样经过新增一拍。

相对 R18 已记录的 request-to-response 数值：

| 路径 | R18 | R20 | delta |
| --- | ---: | ---: | ---: |
| scalar FADD/FSUB S/D/H | 10 | 11 | +1 |
| scalar FMUL/FMA 四族 | 9 | 10 | +1 |
| scalar SCVTF/UCVTF | 8 | 9 | +1 |
| scalar FCVT（含 H source 单 lane） | 7 | 8 | +1 |
| scalar FDIV S/D | 261 | 262 | +1 |
| scalar FDIV H | 518 | 519 | +1 |
| scalar FSQRT S/D | 69 | 70 | +1 |
| scalar FSQRT H | 70 | 71 | +1 |
| NEON ordinary/iterative | 每 slot +1 | — | `+slot_count` |

因此已知 NEON 事务示例为 `.2S` +2、`.4S` +4、`FSQRT.2S` +2；未经过
round-pack 的 CMP、FMIN/FMAX、FRINT、FCVTZS/FCVTZU 与 FMOV latency 不变。

## 定向测试

- H/S/D ordinary normal、minimum-subnormal、FZ/IDC、rounding/IXC、overflow/OFC；

- `pack_result_valid_r` 来源检查及 done exactly-once/回 idle 检查。
