## 1. 完成内容

### rtl/lcvex_l2（统一 L2）

- I/D 共享，64 B line / 256 组 x 2 way = 32 KiB，物理地址
  tag/index/offset，LRU（每组 1 位 MRU）替换，单阻塞 miss，写通。
- 上游接仲裁器（PTW/I-L1/D-L1 请求），下游接延迟注入器/SRAM，
  完全复用 M1-B 协议。
- 读命中 1 拍返回（按请求偏移 rotate8）；未命中从 LRU way 替换并
  8 次 8B 填行；写通（行命中同步更新 + MRU，未命中不分配）；
  下游 fault 上抛；写通被拒作废命中行。
- 修复 tag 位宽：SETS=256 时 index 占 [13:6]，tag=[63:14]。

### 验证

- `sim-sv-l2`：两 way 命中、LRU 替换、写通、写命中行更新、冲突驱逐、
  越界 fault 全过。
- 缓存 TB 握手修正：do_req 改为“保持 valid 直到响应出现”（命中响应
  当拍即被消费，原两拍后撤销会错过 1 拍响应）；三个缓存 TB 统一。
- L2-only 锁步 11 组、**I+D+L2 全缓存锁步 19 组**与 QEMU 一致（含 SVA
  断言）；标准回归与 `make test` 全绿。

## 2. 当前缓存层次

core.imem -> I-L1 -> 仲裁(2) -> L2 -> 延迟 -> SRAM
core.dmem -> D-L1 -> 仲裁(1) -> L2 -> 延迟 -> SRAM
MMU PTW   -> 仲裁(0) -> L2 -> 延迟 -> SRAM

SoC 参数：`I_L1_ENABLE` / `D_L1_ENABLE` / `L2_ENABLE` 可独立开关；
锁步构建 `lockstep-build-l1di`（I+D）、`-l2`（L2 only）、
`-l1dl2`（全缓存）。
