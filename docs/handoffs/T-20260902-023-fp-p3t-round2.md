## 摘要

针对 T-20260902-022 的 STA 复跑结论（`fp_exec/scalar_unit` 仍为
`sys_clk_50` 最差 setup 路径，`req_r.kind[0] -> rsp_r.v_data[81]`，
831 逻辑级，data delay 336.133 ns），本轮把 **T-020 尚未覆盖的剩余
组合操作** 也纳入 `IT_PREP` 两拍路径：

1. 新增 `fp_other_pre_t` 未打包/分类流水中间量：仅保存 format、raw bits、
   `fp_parts_t`（unpacked sign/exp/frac/sig）、FZ flush 标志和 input flags。
2. 新增 `uses_other_pre`：FCMP、FMIN/FMAX/FMINNM/FMAXNM、FRINT、
   FCVTZS/FCVTZU 在发布 `FP_ITER=1` 分支不再单拍组合到 response。
3. `lcvex_fp_scalar` 的 `IT_IDLE -> IT_PREP` 两拍状态机现在覆盖：
   - 原 T-020：ADD/SUB/MUL/FMA/SCVTF/UCVTF/FCVT（pre-round + round/pack）；
   - 本轮新增：CMP/MINMAX/FRINT/FP->int（unpack/flush + finish）。
4. 半精度双 lane（4H/8H）分别用 `pp_other_lo/pp_other_hi` 保存，保持
   每个 16-bit lane 的独立 raw-bit 打包、FCMEQ 全 1/全 0 掩码和
   FPSR.IDC 屏蔽语义。
5. 保持单在途、held response、reset/kill、FPCR snapshot、FPEN trap、
   FCMP NZCV 和 FP→GPR 写回不变；没有动 `lcvex_core.sv`/package/接口。

## 为什么这样切

T-022 的 STA top-N 不是来自已被 T-020 切成两拍的 round_pack 重路径本身，
而是来自 `uses_pre_round` 未覆盖的 **op dispatch / 共享数据通路 /
half-lane 组合**。上一轮 handoff 已明确下一步需要检查
“CMP/MINMAX/FRINT/FP-to-int 仍保持原组合路径”。本轮即针对这些路径，
在 unpack/flush 之后插入寄存器，把“大组合计算”从 request 到 response 的
单拍链拆成两拍：

- 第 1 拍：request/slot mux -> `unpack_fp` + FZ flush -> `pp_other*` 寄存器；
- 第 2 拍：`pp_other*` -> per-op finish（compare/minmax/frint/fp_to_int）
  -> scalar result/int_result/cmp_nzcv -> `lcvex_fp_exec` response 锁存。

这直接打断 `req_r.kind -> scalar_unit 全组合 -> rsp_r` 的 831 级链中
最大的第二段；`pp_other*` 作为新的寄存器边界，使 STA 不再把请求控制位一路
穿到 response 数据位。

## 切级位置

| 路径段 | 本轮边界 |
| --- | --- |
| `fp_exec` slot 选择/operand mux → scalar_unit | 保持组合（少量控制） |
| scalar_unit `unpack_fp` + `FPCR.FZ` flush | 第 1 拍计算，写入 `pp_other_*` |
| CMP 比较/NZCV 生成 | 第 2 拍从 `pp_other_*` 完成 |
| MIN/MAX/NM 选择与 NaN 处理 | 第 2 拍从 `pp_other_*` 完成 |
| FRINT 整数化/舍入/打包 | 第 2 拍从 `pp_other_*` 完成 |
| FCVTZS/FCVTZU 饱和/截断/GPR 结果 | 第 2 拍从 `pp_other_*` 完成 |
| half-lane 双 16-bit 合并 | 第 2 拍分别合并 lo/hi |
| reset/kill | 同时清 `pp_other*` |

## 边界/风险

- 未运行 Quartus synthesis/fitter/STA；实际 Fmax/slack 需由下一轮 FP-P5
  rerun 验证。
- 本轮没有进一步拆分 `round_pack` 本身的 normalize/round 两段；如果下一份
  STA 显示 `pp_pre -> rsp` 或 `pp_other -> rsp` 成为新 top-N，需要再做
  normalize/round 细分。
- `MOV` 和特殊值 DIV/SQRT 仍走短组合路径；当前已知路径未覆盖它们成为
  831 级主链，但属于下一轮可检查项。
- 仅修改 `rtl/lcvex_fp_scalar.sv` 和 `tb/sv/lcvex_fp_exec_tb.sv`，未修改
  `lcvex_core.sv`/package/接口/提交 ABI。
