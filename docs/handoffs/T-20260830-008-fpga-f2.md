## 关键结论

1. **没有继续做 RTL 内部物理拆分，因为第一层拆分已经足够**：
   - 当前隔离副本采用 `A64_FP_SIMD=0`、`L2_SETS=64`、`L2_WAYS=1`，并为 Quartus 21.4 补齐兼容性后，
     所有重型模块 standalone synthesis 均通过，且峰值私有内存 **全部低于 16GB**。
   - L1D、L2、soc_coh、core 分别实测峰值 3.77GB、4.31GB、8.44GB、2.43GB；不再需要把 L1D/L2/soc_coh 内部继续拆成子模块来满足 <16GB 的目标。
2. **发现了能真正跳过顶层重综合的 bottom-up 流程（关键进展）**：
   - 直接用 `quartus_cdb --import_partition` 后马上跑 `quartus_syn` 仍会 `Synthesizing partition "child"`。
   - 正确流程是：顶层工程先用 **black-box stub**（空模块体，只保留端口/参数）完成一次 synthesis；
     再 `quartus_cdb --import_partition` 导入真实 QDB；
     然后运行 **`quartus_sh --flow compile <top> -c <rev> -start fitter -end fitter`**。
     该流程在实验日志中 **未出现 `Synthesizing partition`**，而是直接 `Loading "synthesized" snapshot` 后进入 Fitter。
   - 这证明 block-based bottom-up 可以在 fitter 阶段使用 imported QDB，避免顶层对已分区模块重新做 RTL 综合。
3. `PARTITION_PRESERVE` 类设置在本机 QSF 中未被接受（`set_instance_assignment -name PARTITION_PRESERVE ...` 报 QSF read error），因此不要把它当作当前流程的依赖；采用上述“blackbox synth → import → fitter-only”流程即可。

## Bottom-up 验证记录

### 传统方式（import 后直接 synthesis）——仍然重综合

在 tiny 工程 `qdb_src` 导出 `child.qdb`，`qdb_imp_plain` 导入后执行：

```powershell
quartus_syn --read_settings_files=on --write_settings_files=off qdb_imp_plain -c qdb_imp_plain
```

日志：

```text
Info: Synthesizing partition "root_partition"
Info: Successfully synthesized partition
Info: Synthesizing partition "child"
Info: Successfully synthesized partition
```

结论：仅 import 后跑 `quartus_syn` 不能跳过子分区重综合，和 FPGA-E 一致。

### 正确 bottom-up 流程（blackbox synth → import → fitter-only）

1. 顶层工程使用 black-box stub 定义子模块（同端口/参数、空实现），并给实例加 `PARTITION`。
2. 对该顶层先跑一次 `quartus_syn`（子分区会综合成 GND/空实现，但顶层 elaboration 不需要真实子 RTL）。
3. 导入真实子 QDB：
   ```powershell
   quartus_cdb <top> -c <rev> --import_partition <partition> --file <block>.qdb
   ```
4. 只启动 fitter，不从 synthesis 开始：
   ```powershell
   quartus_sh --flow compile <top> -c <rev> -start fitter -end fitter
   ```

在 `qdb_imp_blackbox` 的实测日志中，第 4 步没有出现 `Synthesizing partition`，而是：

```text
Info (16734): Loading "synthesized" snapshot for partition "root_partition".
Info (16734): Loading "synthesized" snapshot for partition "child".
Info: Running Quartus Prime Fitter
...
Info: Quartus Prime Fitter was successful.
```

因此本流程满足“import 后顶层不再重新综合该 black-box partition”。
