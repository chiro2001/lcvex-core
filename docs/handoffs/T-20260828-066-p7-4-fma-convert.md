# T-20260828-066 P7-4 FMA 与 FP/整数转换垂直实现（owner handoff）

状态：**owner L0–L2 完成**，等待集成者在合并 SHA 复跑并归档。

## 实现摘要

- 标量 fused multiply-add 四族 `FMADD/FMSUB/FNMADD/FNMSUB`（FP32/FP64）：
  fused 整数数据路径，无中间舍入；NaN 优先级 C>A>B（先 SNaN），`0*Inf`/
  `Inf-Inf` 产生 default NaN+IOC；负号按 QEMU `neg_a/neg_n` 在输入上翻转。
- 标量转换：`SCVTF/UCVTF`（W/X 整数/定点 → S/D）与 `FCVTZS/FCVTZU`
  （S/D → W/X 整数/定点），含饱和、NaN→0+IOC、IXC/UFC/IDC、W 零扩展；
  `FCVT S<->D` 按 bit22 反向映射源/目的格式，NaN payload 按 QEMU 映射。
- NEON：`FMLA/FMLS` 与 `SCVTF/UCVTF/FCVTZS/FCVTZU` 的 2S/4S/2D 形式，
  复用 P7-3 three-same/misc 形状边界；2S 写 `Vd[127:64]=0`，lane FPSR OR 合并。
- decode 修正：标量转换分支移到 P7-1 FP 算术分支之后，避免 `rm` 字段误匹配
  （此前 `0x1e232844 FADD s4,s2,s3` 被误判为转换）；向量转换掩码
  `0xbfbf_fc00` 保留 Q 位选择。
- 流水线：新增 `fp_ra`/`neon_fp_ra_en` hazard 与 `fp_conv_*` 载荷；标量
  FP→整数结果走 GPR 写回并在 commit 前保持原子；FPEN trap、backpressure、
  unsupported UDEF 语义与 P7-0/1/3 一致。

## 边界

- 只支持协议选定的 FMA/转换子集；FP16、sqrt、estimate、min/max、round、
  by-element FMA、FMLAL/FMLAL2、向量定点转换、结构化访存、完整 FP
  exception-enable 与 SVE 均不实现，落入 UDEF。
- 不修改 QEMU fork；期望值全部来自 Cortex-A76 QEMU 实测 raw bits。

## 验证

- L0/L1：`make compile`、`make test`（P0 全绿）、P7-4 SV raw unit、
  Cocotb 5/5；既有 P7-1 5/5、P7-2 8/8、P7-3 4/4 无回归。
- L2（A76 required strict lockstep）：P7-1 28/38/18/388、P7-2 31/20、
  P7-3 48、P7-4 94/54/27/142、P6 scalar 40 全部一致。

  40 artifacts（last_seq=79），锁步同时全绿。
- 每个新增编码均有 raw-bit 定向 SV/Cocotb 与 A76 lockstep 覆盖。

## 风险 / 注意

- decode 分支顺序是本次回归暴露并修复的关键点，后续新增 FP 编码时保持
  转换分支在 P7-1 算术分支之后。
- `movz x3,#0x4400,lsl#16; movk x3,#0x2000` 即为 `x3=0x44002000`；
  不要改成 `movk hw=2`（那会得到 `0x200044002000`）。
- Gate D/Gate-F 由集成者在冻结 SHA 上串行复跑。
