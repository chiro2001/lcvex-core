## 实现结论

`round_pack_iter_p1` 的输入来自 DIV/SQRT finish 已寄存的 `fp_pre_t`。`div_finish_pre`
和 `sqrt_finish_pre` 对有限非零商已经写入 `lead` 与 `lead_valid`；特殊值绕过
round/pack，零值保持 `lead_valid=0`。本 lane 将原函数中的 256 位 descending
leading-one fallback 完全移除，改为：

```systemverilog
h = pre.lead_valid ? 32'(pre.lead) : -1;
```

这样 `lead_valid=0` 仍进入既有 zero p1/p2 路径，而正常值直接使用已寄存的 lead。
没有改变 `round_pack_iter_p1` 的格式参数、指数、mantissa、GRS、rounding、sticky、
special/input flags 或任何状态机控制。

## 专用 focused TB

新增 `tb/sv/lcvex_fp_scalar_r21_iter_round_tb.sv`，直接调用私有纯函数并运行
`FP_ITER=1` 路径，覆盖：

- H/S/D 正常预解码 lead 的 mantissa/guard/sticky/discarded 与 exponent metadata；
- `lead_valid=0` 且 `sig` 故意带 set bit 的权威 zero probe，防止 fallback scan 回归；
- H/S/D special bits 与 input flags bypass；
- S tiny sticky（`UFC|IXC`）和 normal tie-to-even rounding（`IXC`）；
- 实际 finite S DIV 与 paired H SQRT finish 的 `lead_valid` 注册、`IT_FIN -> IT_PACK`
  及 `IT_PACK_RESULT` exactly-once 结果窗口。
