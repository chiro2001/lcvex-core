## 实现摘要

- 新增 `rtl/lcvex_neon_fp.sv`：每个活动 lane 复用 P7-1 raw IEEE-754 标量
  unit，合并 FADD/FSUB/FMUL/FCMEQ 的 2S/4S/2D 结果和 FPSR flags。
- `rtl/lcvex_decode.sv` 只接受 Q=0 的 2S、Q=1 的 4S/2D；2S 清 Vd 高 64
  位。只选 quiet `FCMEQ`，FCMGE/FCMGT、FP16 和其它未列族保持 UDEF。
- vector FP 复用 V raw state、NEON hazard/FPEN namespace 和既有单 V commit
  effect，但通过独立 FP execution/effect path 与 NEON integer 隔离；FPSR sticky
  flags 在 commit_fire 时 OR，commit_ready 背压期间不更新。
- 更新 filelist、Make/Cocotb/SV/raw encoder，加入中文设计说明和 A76 required
  48 条定向程序；P7-2 旧 FP 负测改为仍未选的 FCMGE，避免把合法 P7-3 FADD
  当作 UDEF。
