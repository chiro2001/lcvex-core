## 实现摘要

- 新增 `rtl/lcvex_fp_state.sv`：V0～V31 raw 128-bit state；FPCR/FPSR reset、
  `0x07c80000`/`0xf800009f` mask；完整 CPACR 保存和 FPEN 四态 EL0/EL1 权限。
- FP access denied 输出 `exc_code=0x00000007`、
  `exc_esr=0x1fe00000`，对应 QEMU `syn_a64_fp_access_trap(1, 0xe)`；trap
  不更新任何 FP state。
- `commit_valid` 作为已经通过 scalar valid/ready 的 commit_fire；支持同一提交的
  1～4 个不同 V destination 与 FPCR/FPSR post-state，超限/重复拒绝；纯 scalar
  commit 不受 FPEN 影响。
- `difftest_restore_fp_valid` 在同一沿恢复完整 V、masked FPCR/FPSR；既有
  `difftest_restore_sys_valid` 恢复完整 CPACR；restore 优先于同拍 effect。
- `lcvex_pkg.sv` 在既有 scalar commit 字段末尾追加 RTL-only effect 字段和 P7
  sysreg/异常常量；`lcvex_core.sv` 对未接入的新增 effect 字段固定输出零，保持
  现有 scalar core lint/接口兼容。
