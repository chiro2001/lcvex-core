## 实现摘要

- `clk_u59` 保持 100 MHz。`sys_clk_div2` 每个板级上升沿翻转，保持寄存器
  `sys_clk_25` 在每两个板级周期翻转一次，`logic_clk_25=sys_clk_25` 因而为真实
  `/4` 时钟：40 ns 周期、20 ns 高电平、20 ns 低电平。
- frozen top 没有外部 reset 输入；两个 divider 寄存器的显式 `=1'b0` 是确定的
  power-up/reset 相位，首个 logic-clock 上升沿在第二个 `clk_u59` 上升沿之后。
  `lcvex_catapult_a10_reset_gate` 的 `LOGIC_POR_CYCLES=65536` 未改，在 25 MHz
  逻辑域对应约 `2.62144 ms`。
- Qsys `.clk_100_clk` 已直接接回原始 `clk_u59`。生成的 `Qsys.qsys` 明确将
  `clk_100.clk` 接到 `reset_controller_0.clk`、将 `clk_100.clk_reset` 接到
  `emif_bot.global_reset_n`，因此该辅助时钟是实际消费者；CPU/SoC/JTAG/SFL
  继续通过现有 `logic_clk` 别名使用 `logic_clk_25`。
- Qsys `.clk_266_clk(clk_y3)` 及 SDC `clk_y3=3.750 ns` 未改变；EMIF user clock
  仍由 Qsys 生成，未把参考时钟降为 25 MHz，也没有新增功能 CDC。
- SDC 与 RTL 使用同一锚点：
  `create_generated_clock -name sys_clk_25 -source clk_u59 -divide_by 4`
  和 `[get_pins {sys_clk_25|q}]`；原始 `clk_u59=10.000 ns` 与 `clk_y3=3.750 ns`
  同时保留。
