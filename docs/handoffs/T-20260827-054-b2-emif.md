## 验证结论

Verilator 5.050 `--timing --assert -Wall` 下，SV 独立回归全场景通过；Cocotb
3/3 通过。测试包含：

- 128-bit AXI 四拍到单次 512-bit Avalon write/read，以及 `WORDS` 地址换算；
- AW/W 独立握手、B/R hold、随机 active-low `waitrequest_n`；
- B1 lane-form 与规范化窄 WSTRB，line byteenable 检查；
- 跨 64B line、窗口外、非法请求本地 DECERR 且 Avalon 计数不增加；
- `readdatavalid` 延迟、双时钟比例、无丢失/重复；
- calibration success/not-ready/fail、post-accept failure abort、reset flush。

精确 source SHA、seed、命令、退出码和 artifact hash 见
[`docs/tasks/evidence/T-20260827-054.json`](../tasks/evidence/T-20260827-054.json)。

## 风险与边界

- 仍是单 ID、单 outstanding；不支持跨 line 静默拆分，不实现 Avalon error port。
- BFM 是有限仿真内存和校准模型，不代表 Qsys/EMIF 厂商 IP 的错误语义、
  Quartus 生成、STA、CDC signoff 或板级 DDR 稳定性。
- 没有修改 `fpga/catapult_a10/**`、B0/B1、P7/core/pkg/filelist、顶层 Makefile、
  Cache/L2/CPU/SoC、QEMU 或 `scripts/test_registry`；也没有宣称板级完成。
- 平台集成者合并后需在集成 SHA 重跑本任务 SV/Cocotb 子集，并由后续 B3 负责
  Cache/L2 接线；Qsys exact regenerate/板测由 B0/B5 队列负责。
