## 实现摘要

- 按 QEMU 11.1.0 `a64.decode` 增加 `LDCLRP`、`LDSETP`、`SWPP`。编码固定
  `0x19201000/0x19203000/0x19208000`，`rt2=bits[20:16]`，允许非连续、
  非偶数寄存器对；`rt/rt2=31` 或相等时按 UDEF，`rn=31` 作为 SP。
- RTL 复用 CASP 四阶段事务：低读→高读→低计算/写→高计算/写。LDCLRP
  和 LDSETP 的高半新值独立计算，SWPP 交换两个源半；旧低/高值分别写回
  `rt/rt2`，commit packet 以低地址、高地址顺序报告两笔 8B Store。
- 对齐与故障：解码阶段检查虚拟 16B 对齐；MMU 关闭时预检完整物理窗口，
  MMU 打开时保存两半翻译结果并在任何 Store 前检查范围/对齐，避免低半已写
  而高半 fault。acquire/release 位沿用单核 full-barrier 语义。
- 新增 `a64.py` 编码器、`build_hard_lse128_program`、`make p6-lse128`
  （base 与 I+D+L2）、registry 条目 `l2.p6-lse128`，并更新 ISA 范围/缺口文档。
