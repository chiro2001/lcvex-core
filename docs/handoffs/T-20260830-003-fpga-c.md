## 目标与结论

- 目标：消除 `lcvex_fp_scalar.sv` 中超过 64-bit 的 `/`、`%` 除法（Quartus
  `lpm_divide LPM_WIDTHN > 64`），并避免 256-bit 组合 restoring divider 的
  不可接受综合时长。
- **结论：已用 256 拍多周期位串行 restoring 除法替代组合 `/`、`%`，并接入
  core EX 多周期忙等/完成握手。默认 Verilator 编译、FP raw-bit SV TB、
  core smoke 和 P7-1 Cocotb 标量流水线均通过。**
- 未启动 Quartus full flow；未引入 SVE；FP raw-bit/NaN/signed zero/FPSR/
  FPEN/rounding 语义保持。

## 实现摘要

### 新增/修改 RTL

1. `rtl/lcvex_fp_scalar.sv`
   - 新增两个 `lcvex_fp_divider` 实例（低/高 FP16 lane；S/D 只使用低实例）。
   - 新增 `div_finish`：接收多周期除法器产生的商和 sticky，完成 FDIV 的
     NaN/Inf/zero/DZC/FZ 边界与 `round_pack`。
   - `binary_op` 中的 FDIV `/`、`%` 分支已移除；`half_lane_calc` 的 FDIV
     也改走多周期路径。
   - `lcvex_fp_scalar` 增加带默认值的 `clk/rst_n` 输入和 `div_busy/div_done`
     输出。
2. `rtl/lcvex_fp_divider`（同文件底部新模块）
   - 固定 256 拍位串行 restoring division。
   - 每拍只用 64-bit 比较/减法；无大于 64-bit 的除法原语。
   - 输出 256-bit 商和 `sticky`（remainder != 0）。
3. `rtl/lcvex_core.sv`
   - 连接 `clk/rst_n` 与 `div_busy/div_done`。
   - 新增 `fp_div_is_div`，将 FDIV 并入 `ex_busy` 多周期互锁。
   - EX/MEM 在 `fp_div_done` 拍捕获 FDIV 结果，类似现有乘除单元。
4. `rtl/lcvex_neon_fp.sv`
   - 仅为 lane 实例接住新的 `div_busy/div_done` 输出；NEON FP 当前不执行
     FDIV，因此不影响功能。
5. 三个 `lcvex_fp_scalar` SV testbench
   - 添加时钟/复位/`div_busy/div_done` 连接。
   - 对 FDIV 等待前一次彻底空闲并以 `div_done` 作为完成，避免陈旧 done
     脉冲误判（实际调试中发现的测试同步问题）。

## 设计要点与风险

1. **延迟**：每次 FDIV 固定 256 拍。未针对实际前导位做动态缩短，也未做
   高 radix/多 bit 每拍。对后续 FPGA 性能影响需单独评估；当前保正确性优先。
2. **面积**：FP16 使用两个并行除法器（低/高 lane），S/D 仅用一个；若需要
   省面积可后续改为分时复用。
3. **集成边界**：`lcvex_fp_divider` 与 `lcvex_fp_scalar` 同文件，使用
   `/* verilator lint_off DECLFILENAME */`；未新增 filelist 条目。
4. **未执行**：Quartus full flow / STA / 上板；QEMU strict lockstep；
   Gate D/L3。本任务只做 RTL 级定向与 core/Cocotb 验证。
5. **语义**：所有 raw-bit 定向测试通过；核心改动只是把 FDIV 变成多周期，
   不改变 FPCR/FPSR/NaN/rounding 路径。
