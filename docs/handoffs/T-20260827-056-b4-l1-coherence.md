## 边界与风险

- `L1_PROBE_ENABLE=1` 是 B4 wrapper 的正式路径；B3 L2-only 入口保持默认 0。
- 单核 blocking L1 在自身下游事务期间不能回答 snoop；wrapper 用
  `l1_probe_block` 让 L2 在该窄窗口跳过 probe，当前 L1 事务已先序列化自身
  victim writeback。
- 目前没有系统/SoC 接线、I-L1、AXI/EMIF、QEMU lockstep 或多核一致性证明。
- L2 drain fault 的 fault level 在失败 epoch 内可见；释放 quiesce 后由新 epoch
  清理，成功 ack 永不与 fault 同时出现。
