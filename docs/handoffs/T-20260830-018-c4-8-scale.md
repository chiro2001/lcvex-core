## 规模趋势与代理

- 目录位图：`SHARER_W = CORE_COUNT = 8`，`OWNER_W` 在 RTL 中仍是 8-bit one-hot
  （不是压缩 3-bit 编码）。
- 每行目录元数据估计：`valid(1) + state(2) + sharers(8) + owner(8) + dirty(1) + pending(1)`
  = 21 bit/line，`MEM_LINES=1024` 时约 21504 bit。
- 8核 smoke 的 probe 串行：Upgrade 和 ReadUnique 均依次 probe 7 个旧 sharer；
  当前为单事务、逐目标 probe，未做并行 probe 扇出。
- PoC 仍为 8B beat、64B line = 8 beats/refill/writeback，未改变。
- 平均事务延迟 proxy：17 cycles（含 refill/probe/写回）；21 transactions / 403 cycles
  ≈ 0.0521 transactions/cycle，受全局单事务与逐 probe 限制。
