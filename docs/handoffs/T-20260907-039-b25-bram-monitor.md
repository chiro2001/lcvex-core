## 完成内容

- `SOC_BRAM` 固定为 `[0x00000000,0x00010000)`；`SOC_BRAM_STACK_BASE=0xF000`，linker 将栈顶固定为 `0x10000`。
- BRAM wrapper 和 standalone `altera_syncram` wrapper 默认 64 KiB（8192×64 bit）；综合路径使用显式 `init_file` 和 `power_up_uninitialized("FALSE")`。平台 top 在仿真选择 byte HEX，在 Quartus 选择 `../boot/build/boot.mif`。
- `boot.S` 改为 BRAM 常驻 monitor：输出 `LCVEX25 BOOT`、`CAL-*`、`DDR-*`、`READY`；校准失败/超时不死循环；实现 `p`、`?`、`m` 和可打印字符 echo。UART 每个 DATA 写入先检查 CONTROL.WSPACE，满时有限等待后直接丢弃字符且不发起 DATA 访问，避免 host 未连接或 vendor FIFO 满时卡死。
- DDR magic test 使用五条 16 KiB 同 set 地址，驱动现有 L1/L2 eviction/writeback 后再读回第一条 magic，供 SoC TB 以 adapter read/write counter 证明非 cache self-hit。
- `bin_to_mif.py` 从同一 `boot.bin` 生成逐字节 little-endian HEX 与全深度 `WIDTH=64 DEPTH=8192` MIF，并逐字节回读 HEX/MIF；产物不进 Git。
