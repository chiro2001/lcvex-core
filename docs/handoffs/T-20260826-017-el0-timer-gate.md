## 目标与边界

补齐 EL0 对 Generic Timer 系统寄存器的 `CNTKCTL_EL1` 权限门控，使禁止访问
产生与 QEMU 一致的 System Register Trap，而不是错误地当作 UDEF；不改变
EL1 timer、WFI/WFE 或 QEMU 参考实现。

## 实现摘要

- `lcvex_decode` 按 QEMU `gt_counter_access/gt_timer_access` 门控：
  - `CNTPCT/CNTPCTSS` 用 bit0，`CNTVCT/CNTVCTSS` 用 bit1；
  - physical timer 的 `TVAL/CTL/CVAL` 用 bit9，virtual timer 用 bit8；
  - `CNTFRQ_EL0` 仅在 bit0/1 至少一位为 1 时允许。
- 拒绝访问生成 `EC=0x18` 和完整 `SYSREG_ISS`（方向、寄存器编码、Rt），
  由 core 将该 ESR 在异常提交时写入 `ESR_EL1`；`ELR_EL1=faulting PC`，
  `FAR_EL1` 不更新。
- 新增 `hard_timer_el0` 生成器、`make p6-timer-el0` 和 registry L2 入口。
  镜像在 gate=0、逐步开放 bit0/bit9/bit8 的各边界执行 MRS/MSR 和异常返回。
