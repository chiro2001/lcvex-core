## CDC/reset 静态分析

- **Gray/pointer 同步**：request_fifo 与 response_fifo 均采用 ADDR_WIDTH+1
  Gray 指针、两拍跨域同步器；source 侧 Gray 指针 -> 接收域第一级同步器的
  路径已在 SDC 中用 `set_false_path` 切断并加 `set_max_delay 2.000` 占位，
  供 TimeQuest/Report CDC 复核。满/空判定基于接收域第二级 Gray 指针，
  属于标准异步 FIFO 结构。
- **非对称复位**：CPU 或 EMIF 任一域复位（或 `cal_fail`）都会使
  `link_rst_n_req` 拉低，从而同时清空两个 FIFO 的写/读指针与同步器。
  release 时两个域分别通过自己的时钟边沿退出复位，允许两域复位释放存在
  自然偏斜。适配器在 FIFO 读写使能上增加了本域 `cpu_fifo_rst_n` /
  `emif_fifo_rst_n` 就绪条件，避免一侧已释放但另一侧仍复位时提前访问 FIFO；
  已接受的 Avalon 读仍由既有 `DRAIN` 行为防迟到 `readdatavalid`。
- **公共异步复位释放**：公共请求是异步断言；每个域内两拍
  async-assert / sync-deassert 同步器生成 `cpu_fifo_rst_n` /
  `emif_fifo_rst_n`，取代原先直接把原始 `link_rst_n` 接到两个 FIFO 域的
  做法。SDC 为同步器首级对 EMIF/平台复位源的路径增加 guarded false_path，
  但 recovery/removal 仍需真实 TimeQuest 检查。
