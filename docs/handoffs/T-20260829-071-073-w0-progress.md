## 1. 执行口径

dsh 工具模式是本项目默认执行模式。**禁止使用 bash `sleep` 循环或
`while kill -0 ...` 等待/调度 subagent**；subagent 完成由 harness 自动通知，
收件核对在收到完成通知后执行。`sleep` 只允许用于等待外部世界（远端宿主、
物理板、人工操作）。该口径已同步写入：

- `docs/MULTI_AGENT_WORKFLOW.md` §2.2.0 / §2.2.2 / §2.2.6 / 禁止事项 / §2.2.7
- `docs/decisions/ADR-20260828-004-dsh-control-plane.md` 决定 2

主/集成 Agent 默认按 A/B/C 三条线**尽可能并行**调度，只有真实依赖、计划中的
汇合点/门、共享热点或资源冲突才串行。单线 blocker 不阻塞其它线的独立任务。
该规则已写入 `docs/MULTI_AGENT_WORKFLOW.md` §2.2.7 和
