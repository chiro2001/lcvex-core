## 实现摘要

- `lcvex_fp_scalar.sv` 用固定宽度整数中间值实现 FP32/FP64 的 FMOV、FADD、
  FSUB、FMUL、FDIV、FCMP；无 `real`/host float/epsilon。
- 加法保留 128 个额外低位抵抗 cancellation，除法保留 128 位商并将余数
  压入 sticky；四种 FPCR.RMode、DN、FZ、NaN/零/Inf/subnormal 和 FPSR
  sticky flags 有明确位级路径。
- decoder 支持 scalar FMOV register/immediate、S/D 三元算术、quiet FCMP
  register/#0，以及 unsigned-offset S/D LDR/STR；FCMPE、FP16、向量/结构化
  访存等保留编码明确 UDEF。
- core 将 FP 载荷贯穿 ID/EX、EX/MEM、MEM/WB，增加 V 前递和 FP load-use
  停顿；V/FPSR 由 `commit_fire` 送入既有 `lcvex_fp_state`，FPEN trap、
  dmem fault、commit backpressure 均无错误 FP 副作用。
- `rtl/filelist.f`、Makefile、SV/Cocotb 入口和 raw 定向程序均已接入。QEMU
  仍使用既有 11.1.0/0012 wire；未修改 QEMU fork。

## 风险和边界

1. 256-bit 组合整数路径和 256-bit 除法适合当前可综合 PoC，但可能成为 FPGA
   时序瓶颈；需在 B5 SoC 接入/Quartus STA 前做资源与时钟收敛，不能把本任务
   的 Verilator 通过当作上板时序通过。
2. scalar FP memory 目前只覆盖自然宽度 unsigned-offset 单寄存器；unscaled、
   pre/post、pair、lane、结构化和向量访存留待后续任务。
3. 本任务不是完整 ARMv8.2-A FP/NEON 合规；FMA、sqrt、转换、FP exception
   enable、FP16、NEON、SVE 均未实现。
4. 集成者必须在 cherry-pick/merge 后复跑任务要求的 L0–L2，并在任务 JSON 中
   记录最终状态；Gate F、Cache/AXI/FPGA 不属于本任务。
